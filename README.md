🟣 SW Economy

Bot global de economía para Discord.

💰 Características

- Sistema de economía por servidor.
- Moneda configurable.
- Balance de usuarios.
- Trabajo y recompensas.
- Daily.
- Transferencias.
- Ranking económico.
- Configuración mediante "/setup eco".
- Sistema de presupuesto del servidor.
- Logs de economía.
- Guía mediante "/guía".
- Configuración independiente para cada servidor.

⚙️ Comandos principales

"/setup eco" — Configura el sistema de economía.

"/balance" — Consulta tu dinero.

"/daily" — Reclama tu recompensa diaria.

"/work" — Trabaja y gana dinero.

"/pay" — Envía dinero a otro usuario.

"/leaderboard" — Consulta el ranking económico.

"/guía" — Recibe la guía del bot por mensaje privado.

🌎 Bot global

La configuración de cada servidor es independiente. Los datos de un servidor no afectan a los demás.

🔐 Seguridad

El token del bot debe mantenerse privado y configurarse mediante variables de entorno.

🚀 Inicio

El bot utiliza:

- Node.js
- Discord.js
- Express

Comando de inicio:

"node index.js"
